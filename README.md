# 🛒 GoCart | Multi-Vendor Marketplace

**GoCart** is a comprehensive, full-stack e-commerce ecosystem. It features a triple-tier architecture providing tailored experiences for **Customers**, **Store Owners**, and **Platform Administrators**. Integrated with Stripe for secure global payments and a robust analytics engine, GoCart is built for scale.

## 🚀 Triple-Tier Architecture

### 1. Customer Experience
- **Dynamic Shopping**: Browse products with advanced filtering and search.
- **Cart Management**: Real-time cart updates with persistent storage.
- **Secure Checkout**: Powered by **Stripe Gateway** for seamless transactions.

### 2. Store Owner Dashboard
- **Sales Analytics**: Visual data on revenue and order volume.
- **Inventory Management**: Add, edit, and track product stock levels.
- **Order Processing**: Manage incoming customer orders and fulfillment status.

### 3. Admin Control Center
- **Platform Analytics**: High-level overview of total marketplace performance.
- **Store Governance**: Review and approve new store applications.
- **Promotion Engine**: Create and manage discount coupons across the platform.
- **Vendor Management**: Global control over all registered stores and users.

---

## 🛠️ Tech Stack

- **Frontend**: Next.js (App Router), React, Tailwind CSS
- **Backend**: Next.js API Routes (Serverless)
- **Database**: MongoDB & Mongoose
- **Payments**: Stripe API & Webhooks
- **Authentication**: NextAuth.js (with Role-Based Access Control)
- **Deployment**: Vercel
